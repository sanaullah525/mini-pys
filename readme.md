# 🐍 Python Automation and Scripts

This repository contains Python scripts built during my journey of learning coding and systems automation. It includes a mix of independent utilities, as well as scripts adapted from technical books, blogs, and instructional videos.

## 🚀 Repository Focus

* **Task Automation:** Scripts designed to handle repetitive system tasks, file operations, and data processing.
* **Practical Learning:** A central place to practice translating manual workflows into repeatable Python code.
* **Resource Utilization:** Practical implementations of foundational scripting concepts learned from various tech tutorials.

## 🛠️ Concepts Covered
* **Language:** Python 3.x
* **Core Logic:** Functions, loops, conditional statements, and basic error handling.
* **System Operations:** Interacting with files, parsing text, and organizing directories.

## 🚀 Task Automation
* **File Operations:** Scripts to create, read, update, and delete files and directories.
* **Data Processing:** Scripts to parse and manipulate structured data (e.g., CSV, JSON).
* **System Monitoring:** Scripts to monitor system resources and generate reports.
